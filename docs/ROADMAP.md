# План работ

Документ ведётся вместе с историей коммитов: пункт считается готовым, когда он
зелёный в CI (Rust: fmt + clippy `-D warnings` + test; фронтенд: tsc + eslint +
prettier + vitest + build).

## Этап 1 — ядро (готово)

Хранилище и вся логика без привязки к Tauri, чтобы её можно было тестировать без GUI.

- [x] Каркас воркспейса, доменные модели, лимиты и нормализация ввода
- [x] SQLite: схема, миграции через `user_version`, пул соединений, WAL
- [x] Заметки: CRUD, корзина, архив, закрепление, цветовые метки, дубликаты
- [x] Папки: дерево, пути, защита от циклов, удаление с подъёмом содержимого
- [x] Теги: регистронезависимая уникальность, слияние при переименовании
- [x] Поиск: FTS5, индекс текстом без разметки, язык запроса, сниппеты, bm25
- [x] История версий: снапшоты, откат, чистка по политике
- [x] Сейф: PBKDF2 + AES-256-GCM, контейнер `BKENC1`, смена пароля с перешифровкой
- [x] Синхронизация: манифесты устройств, трёхстороннее слияние, per-device файлы
- [x] Экспорт/импорт: Markdown + front-matter, JSON-связка, HTML-документ
- [x] Тесты: 142 модульных + 46 интеграционных

- [x] Палитра команд `Ctrl+K`
