# Bookmarks

**Локальный блокнот на Tauri 2 + React 19 + Rust.**
Markdown, дерево папок, теги, мгновенный полнотекстовый поиск, история версий,
шифрованный сейф и синхронизация между устройствами — без аккаунтов и облака
посредника.

Rust-ядро · SQLite + FTS5 · AES-256-GCM · Windows-first

</div>

---

## Зачем

Заметочников много, но почти все они либо облачные (данные у провайдера), либо
локальные, но без внятного поиска и истории. Bookmarks собран так, как будто это
корпоративный инструмент: данные лежат в одном SQLite-файле на вашем диске,
поиск работает мгновенно и офлайн, а синхронизация — это обычная папка (локальная,
сетевая или WebDAV), в которую приложение пишет шифрованные контейнеры.

## Что уже работает

**Ядро (`crates/bookmarks-core`, чистый Rust, без Tauri):**

| Возможность | Как сделано |
|---|---|
| Заметки, папки, теги | SQLite, нормализация и лимиты в доменном слое, уникальность имён папок без учёта регистра |
| Мгновенный поиск | FTS5 с портер-стеммингом, индекс поддерживается триггерами; в индекс попадает **текст без разметки**, а не исходный Markdown |
| Язык запроса | `"точная фраза"`, `tag:работа`, `#тег`, `folder:Проекты`, `is:pinned`, `has:task`, `color:red`, `after:2026-01-01`, `-исключение` |
| История версий | Снапшот перед каждым изменением, откат (обратимый), чистка по политике `keep_recent` / `keep_days` |
| Сейф | PBKDF2-HMAC-SHA256 (210 000 итераций) → AES-256-GCM, контейнер `BKENC1` с собственной солью и nonce; тело зашифрованной заметки **исключено из поискового индекса** |
| Синхронизация | Трёхстороннее слияние, per-device пространство имён, детерминированное разрешение конфликтов, проигравшая версия уходит в историю |
| Экспорт / импорт | Markdown-каталог с YAML front-matter (совместим с Obsidian/Hugo), JSON-связка для бэкапа, единый HTML для печати |
| Обслуживание | `integrity_check`, пересборка индекса, поиск дубликатов по хешу, автоочистка корзины |

**Интерфейс (React 19 + TypeScript + Tailwind v4):**

- трёхколонный рабочий стол: дерево папок → виртуализированный по страницам список → редактор;
- редактор Markdown с тулбаром, режимы «текст / рядом / вид», автосохранение с доводкой при закрытии;
- палитра команд `Ctrl+K` (действия + заметки + папки в одной выдаче);
- светлая и тёмная темы, 8 акцентных цветов, RU/EN, переключатель анимаций;
- кастомная строка заголовка под окно без рамки;
- браузерный демо-режим: `npm run dev` работает без Rust-тулчейна на том же контракте IPC.

## Архитектура

```
crates/bookmarks-core/    ядро: домен, хранилище, поиск, версии, крипто, синк, экспорт
src-tauri/                обёртка: окно, IPC-команды, лоток, автозапуск, бэкапы
src/                      интерфейс: React 19, Tailwind v4, zustand, react-query
```

Принцип разделения: **ядро не знает о Tauri**, обёртка не знает о SQL, а
интерфейс не вызывает `invoke` напрямую — только через контракт `Backend`
(`src/api/backend.ts`). Благодаря этому ядро покрыто тестами без GUI, а UI
тестируется на демо-хранилище.

Контракт IPC описан в двух местах — `src/api/contracts.ts` и
`bookmarks-core::domain`; они меняются только вместе, и это фиксируется в
сообщении коммита.

## Сборка

```bash
# зависимости
npm install

# интерфейс в браузере (демо-режим, без Rust)
npm run dev

# тесты и проверки
npm run test:run          # vitest
npm run typecheck         # tsc
npm run lint              # eslint
cargo test --workspace    # Rust
cargo clippy --workspace --all-targets -- -D warnings

# десктопное приложение
npm run tauri dev
npm run tauri build       # NSIS/MSI на Windows
```

Требуется Rust 1.82+ и Node 20+. На Linux для `tauri dev` нужны
`libwebkit2gtk-4.1-dev`, `libgtk-3-dev`, `librsvg2-dev`; само ядро
(`cargo test -p bookmarks-core`) собирается без них.

## Безопасность

- Пароль сейфа никуда не отправляется: из него выводится ключ, в базе хранится
  только верификатор (blake3 от отдельного доменного ключа).
- Ключ живёт в памяти процесса и обнуляется при блокировке; после перезапуска
  сейф заблокирован.
- Восстановления пароля нет — это осознанное решение: если бы оно было,
  шифрование ничего бы не значило.
- Превью Markdown проходит через DOMPurify, поэтому чужой импорт не может
  выполнить скрипт в окне приложения.
- Пути в удалённом хранилище проверяются: `../` и абсолютные пути отвергаются.
